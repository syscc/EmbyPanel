# 版本更新日志

## v0.3.1

发布时间：2026-11-08

### 新增

- 链路诊断列表新增本页记录、缓存命中与异常数量摘要，以及请求取消状态展示。
- 新增诊断页面回归，覆盖紧凑列表、长失败路径、取消前缀兼容和详情文本保留。

### 优化

- 链路诊断由完整步骤大卡片改为紧凑记录列表，集中展示请求 ID、服务器、媒体、客户端和单步耗时。
- 完整路径、URL 与错误内容移至详情弹窗，列表仅保留节点摘要；详情复用统一弹窗外壳，以步骤时间线呈现，保留滚动正文与固定关闭操作。
- 优化筛选区、状态徽标、分页布局及窄屏展示，沿用现有明暗主题并补齐英文翻译。

### 修复

- 修复单条诊断的长 URL 和详细文本过度占用列表空间的问题。
- 区分失败、取消与跳过步骤，取消前缀兼容冒号后有、无空格；不把 0 ms 当作失败，也不将单步耗时伪装为请求总耗时。
- 隔离缓存状态圆点样式，避免未命中标记受到全局在线状态样式影响。
- 筛选忙碌时改用只读输入，保留键盘提交后的焦点；详情关闭后恢复触发按钮焦点。

### 验证

- 独立 reviewer 两轮静态审查完成，最终结论为 `Merge verdict: OK`。
- Playwright 使用合成接口验证桌面与 320–768px 窄屏、明暗主题、中英文、筛选分页、长路径详情与键盘焦点；未连接真实 Emby 数据。
- `cargo fmt`、`cargo fmt --check`、`cargo check --locked`、`cd frontend && npx vue-tsc -b --noEmit` 和 `git diff --check` 通过。
- `node --test frontend/tests/review-regressions.cjs`：48 项通过；`cd frontend && npm run build` 通过。
- 本次后端仅更新版本号，未重跑 Rust 全量测试；未执行本地 Rust release 构建，未打包二进制。

## v0.2.8

发布时间：2026-11-07

### 新增

- 新增实时会话中心，支持自动刷新、播放详情、停止播放和发送消息，展示码率、转码原因、客户端与设备信息。
- 新增媒体库与计划任务管理，支持库列表、路径验证、扫描进度、任务执行/取消及失败历史查询。
- 新增播放链路诊断中心，记录 Emby Path、映射、OpenList、raw_url、缓存和 302 各节点的耗时、命中规则与失败信息。
- 新增历史分析，支持用户、媒体、服务器和客户端维度的趋势，以及 302 成功率、延迟 P95、转码率和带宽指标。
- 新增缓存管理，支持容量与命中率查看、条目搜索分页和按服务器/媒体范围清理。
- 新增告警中心，支持规则、静默期、重试、投递历史、恢复通知和取消失效投递。
- 新增多管理员安全管理，支持 RBAC、服务器级授权、TOTP 二次认证、恢复码、API Token 和登录会话撤销。
- 新增服务器级 OpenList、STRM 映射、缓存、内部重定向和巡检策略覆盖，默认继承全局配置；Web UI 拦截支持自定义状态码与提示文本。

### 优化

- 完善反代响应流式传输，需改写的文本响应限制为 8 MiB；配置差量热更新后旧连接自然排空，进程退出采用 30 秒排空预算。
- SQLite 高频统计写入采用 WAL、`busy_timeout` 和有界 `TelemetryWriteQueue`，将批量持久化移出请求主链路。
- Emby 请求明确超时，多服务器监控和补充查询保留有界并发、整体截止时间及部分失败结果。
- 历史、安全、会话、任务和缓存页面独立加载授权服务器选项，保存配置后刷新选项；媒体库、任务、失败详情及缓存条目按稳定服务器 ID 映射配置名称。
- 任务失败与告警投递历史接入保留维护：90 天、维护后全局最多 20,000 条，按小时节流，维护间隔内可暂时超过条数上限。
- 补充升级、备份与回退说明，区分配置导出和停服后的完整数据目录冷备，说明数据库、独立密钥及外部 2FA 密钥的恢复边界。

### 修复

- 修复用户策略保存后的弹窗状态，成功后关闭，失败保留错误与编辑内容；删除用户先明确确认，取消不发送删除请求，后端继续核验目标用户名。
- 修复确认弹窗层级及关闭后的焦点恢复，避免从策略弹窗发起确认时被遮挡或错误抢回焦点。
- 修复缓存全量清理能力与全局统计可见性混用，独立返回并使用 `canCleanupAll`，后端按写权限与服务器授权范围校验；条目加载失败时清空旧列表和翻页状态，并明确区分缓存条目 ID 与媒体 ID。
- 修复缓存键的服务器隔离，使用版本化结构键并兼容旧普通键，避免含冒号的服务器 ID 引起范围混淆。
- 播放控制改为独立 `sessions.control` 权限，既有只读 Token 不自动获得写权限；API Token 签发在同一事务中核验来源会话、当前权限和显式服务器授权。
- 修复认证及授权边界，401 与 403 分开处理；空服务器授权返回空列表，指定未授权服务器返回 403，不误清退登录，并完善注销、密码修改及旧会话撤销。
- 修复历史、活动日志、请求详情、拦截日志、CSV 和告警历史的授权过滤与截断顺序；历史统计先筛选有效样本，按稳定 ID 汇总服务器改名数据，比例按权重计算，P95 不作错误汇总，并提示采样截断边界。
- 修复实时任务错误、持久化历史及上游失败回退中的敏感信息暴露，统一遮盖 URL 认证信息、签名和凭据字段变体；常规配置读取不下发 Emby API Key 明文。
- 修复告警迟到响应覆盖当前状态、失效投递重试、诊断手动跳页被重置及服务器选项跨配置或跨登录回填的问题，并加强初始化竞态与可信代理 CIDR 校验。

### 验证

- 发布前源码回归：`cargo test --locked --quiet` 471 项通过；`node --test frontend/tests/review-regressions.cjs` 37 项通过。
- 发布前源码检查：`cargo fmt`、`cargo check --locked`、`cd frontend && npx vue-tsc -b --noEmit` 与 `git diff --check` 已通过。
- 后端使用临时数据库、生产 Router 与本地回环 mock 覆盖权限、会话、统计、告警及旧库迁移；完整目录冷备恢复回归使用合成数据核对管理员权限、撤销状态、TOTP/恢复码与告警密钥。
- 前端回归在内存中执行源码，HTTP、加密和定时器使用模拟；此前 Playwright 使用合成授权与 API 检查桌面/手机路由及关键交互，不代表真实上游验收。
- 本轮未重跑真实 Emby/OpenList 版本矩阵或公网 Webhook；配置导出不包含管理员、安全凭据、告警及历史等完整状态，也不包含 Emby 自身数据，完整恢复边界见 `docs/upgrade.md`。

### 新增

- Docker 启动日志增加项目名称、项目地址、项目版本号和管理 UI 地址。
- 新增 `/api/app-info` 接口，前端左上角版本号从后端读取，不再硬编码。
- Docker 构建时自动把 Git tag 注入容器版本号，例如 `v0.0.5`。

### 优化

- 服务器配置里的 `Emby API Key` 默认隐藏，改为眼睛按钮切换显示/隐藏。
- 管理员登录后，服务器配置页面支持查看已保存的 `Emby API Key`。
- 源码运行时版本号与 `Cargo.toml` 保持一致。

### 验证

- `cargo fmt --check`
- `cargo clippy --all-targets -- -D warnings`
- `cargo test`
- `cd frontend && npm run build`
- `cargo build --release --locked`

## v0.0.4

发布时间：2026-05-24

### 修复

- 过期面板登录态请求不再写入容器运行日志。
  - 旧浏览器页面、旧手机页面或未刷新的面板标签页可能继续用失效 token 轮询接口。
  - 这类请求属于正常鉴权拒绝，不影响 Emby 反代和播放，不再输出 `invalid or expired session` 日志。

## v0.0.3

发布时间：2026-05-24

### 修复

- 修复 Docker 容器重启后旧页面继续轮询导致 `invalid or expired session` 反复刷错误日志的问题。
  - 面板接口返回登录过期后，前端会自动清理本地登录状态、停止轮询并回到登录页。
  - 后端将登录过期类请求从 `ERROR` 降为 `INFO`，避免正常会话失效刷屏污染错误日志。

- 修复容器重启后旧页面可能使用旧 RSA 公钥提交登录或配置请求，导致 `failed to decrypt request key: decryption error` 的问题。
  - 前端每次提交加密请求前都会重新获取当前后端公钥。
  - `/api/public-key` 返回 `Cache-Control: no-store`，避免浏览器或中间代理缓存旧公钥。
  - 解密失败这类请求格式问题调整为 `WARN` 日志。

## v0.0.2

发布时间：2026-05-24

### 修复

- 修复客户端 UA 拦截误命中问题。
  - 之前 UA 拦截会同时参考 `X-Emby-Client` 客户端名，可能出现规则 `infuse-library` 误拦 `Infuse-Direct` 类型客户端。
  - 现在 UA 拦截只按实际 `User-Agent` 做大小写不敏感关键词匹配。
  - 示例：规则 `infuse-library` 只会命中包含 `Infuse-Library` 的 UA，不会仅因为客户端类型是 `Infuse-Direct` 而拦截。

- 修复容器日志时间显示不易阅读的问题。
  - 之前 tracing 默认输出 UTC RFC3339，例如 `2026-05-24T03:06:09.524129Z`。
  - 现在按 `TZ` 环境变量输出 24 小时制本地时间。
  - Docker 默认 `TZ=Asia/Shanghai` 时，日志格式为 `2026-05-24 11:06:09.524`。

## v0.0.1

发布时间：2026-05-24

### 首个版本

- Rust 后端 + Vue 前端管理面板。
- 多 Emby 服务器反代端口配置。
- STRM 直链识别和 HTTP 302 重定向。
- OpenList `/d/...` 路径解析为 `raw_url`。
- 直链缓存、缓存容量限制、缓存域名黑白名单。
- STRM URL 映射，支持普通替换和 `regex:` 正则规则。
- 内部 HEAD 跳转解析。
- 客户端 UA 拦截、播放频率限制、IP 屏蔽、用户禁用和解除封禁。
- Webhook 命中通知。
- 实时播放、播放日志、运行信息日志。
- Docker Compose 部署和 GitHub Actions 多架构 Docker 构建。
